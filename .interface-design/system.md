# CareerOS v5 Design System Contract

## 1. Palette & Surface Tokens
- **Canvas / Background (Light)**: `#F8FAFC` (Slate 50)
- **Cards & Surfaces (Light)**: `#FFFFFF` (Pure White) with `1px solid #E2E8F0` (Slate 200)
- **Navigation / Headers**: `#FFFFFF` with bottom border `1px solid #E2E8F0`
- **Primary Text**: `#0F172A` (Slate 900)
- **Secondary / Muted Text**: `#64748B` (Slate 500)
- **Primary Accent**: `#2563EB` (Royal Blue / Indigo)
- **Success / Match**: `#059669` (Emerald 600)
- **Warning / Pending**: `#D97706` (Amber 600)
- **Destructive / Error**: `#DC2626` (Rose 600)

## 2. Graph Visualization Color Scheme (Categorical & High-Contrast)
- **Person / User Nodes**: `#2563EB` (Royal Blue)
- **Skill Nodes**: `#059669` (Emerald Green)
- **Company Nodes**: `#D97706` (Amber)
- **Role / Opportunity Nodes**: `#7C3AED` (Violet)
- **Domain / Tag Nodes**: `#0891B2` (Cyan)

## 3. Typography & Spacing
- **Font Family**: Inter, system-ui, -apple-system, sans-serif
- **Metric Figures**: `tabular-nums`
- **Card Radius**: `12px` (`rounded-xl`)
- **Button Radius**: `8px` (`rounded-lg`)
- **Card Shadow**: `0 1px 3px 0 rgba(0, 0, 0, 0.05), 0 1px 2px -1px rgba(0, 0, 0, 0.05)`
